# Spring Boot + PostgreSQL: Java AppHost

The AppHost itself is written in **Java** (preview). It runs a Spring Boot 4 notes
API **natively** through the project's Maven wrapper, next to PostgreSQL.

| Resource | Runs as | Integration |
|----------|---------|-------------|
| `api` | native `./mvnw spring-boot:run` | `addSpringBootApp` (`Aspire.Hosting.Java`, preview) |
| `pg` / `notesdb` | PostgreSQL container + database | `addPostgres().addDatabase()` |

```java
var db = builder.addPostgres("pg").addDatabase("notesdb");

builder.addSpringBootApp("api", "./api")
    .withReference(db)
    .waitFor(db)
    .withHttpHealthCheck(new WithHttpHealthCheckOptions().path("/actuator/health"));
```

The Java SDK in `.aspire/modules/` is generated by `aspire restore` from the
packages in `aspire.config.json`; don't edit it by hand.

## Prerequisites

- Aspire CLI 13.6.4 and the .NET 10 SDK
- **JDK 25** on `PATH` (the AppHost is compiled with `javac --release 25`; the API targets Java 21)
- Docker (for PostgreSQL). Maven is not required: `api/mvnw` downloads it.

> **Windows:** Aspire 13.6's generated Java client can hang during named-pipe
> authentication ([microsoft/aspire#20056](https://github.com/microsoft/aspire/issues/20056)).
> Run this sample on Linux or macOS, or use the repository's
> [Linux validation runner](../../../docs/samples-and-development.md#linux-validation-for-windows-preview-hosts).

## Run

```bash
cd samples/preview/spring-boot-postgres
aspire run --apphost AppHost.java
```

This is an API demo (no web UI). Copy the `api` URL from the dashboard, then:

```bash
curl -X POST "$API/api/notes" -H "Content-Type: application/json" \
  -d '{"title":"Hello","content":"My first note"}'
curl "$API/api/notes"
curl "$API/actuator/health"
```

In the dashboard, **Structured logs** shows `Created note id=1 title="Hello"` and
**Traces** shows each request with its Hibernate/JDBC spans.

## How it is wired

- `addSpringBootApp` launches `spring-boot:run` with the wrapper and supplies
  `SERVER_PORT`, which Spring Boot reads for its listening port.
- `withReference(db)` injects `NOTESDB_JDBCCONNECTIONSTRING`, `NOTESDB_USERNAME`, and
  `NOTESDB_PASSWORD`; [`application.properties`](api/src/main/resources/application.properties)
  maps them onto the Spring datasource.
- `waitFor(db)` holds the API until the database exists; the actuator health
  endpoint (which includes a database check) gates dependents.
- Telemetry comes from the **OpenTelemetry Spring Boot starter**, an in-app SDK that
  reads Aspire's `OTEL_*` settings and bridges Logback to OTLP logs. Compare with
  [java-javalin-redis](../../java-javalin-redis), which uses the zero-code Java agent.

## Tests

```bash
cd api
./mvnw verify
```

Tests use an in-memory H2 database in PostgreSQL mode; Docker is not needed.
