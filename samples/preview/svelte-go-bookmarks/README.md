# Bookmark Manager: Go AppHost + Go API + Svelte

The AppHost itself is written in **Go** (preview). It orchestrates a Go API that
runs **natively**, a Svelte 5 frontend on Vite, and PostgreSQL.

| Resource | Runs as | Integration |
|----------|---------|-------------|
| `api` | native Go process (`go run .`) | `AddGoApp` (`Aspire.Hosting.Go`, preview) |
| `frontend` | Vite dev server | `AddViteApp` |
| `pg` / `bookmarksdb` | PostgreSQL container + database | `AddPostgres().AddDatabase()` |

```go
db := builder.AddPostgres("pg").AddDatabase("bookmarksdb")

api := builder.AddGoApp("api", "./go-api").
    WithReference(db).
    WaitFor(db).
    WithHttpEndpoint(&aspire.WithHttpEndpointOptions{Env: aspire.StringPtr("PORT")})

builder.AddViteApp("frontend", "./frontend").WithReference(api).WaitFor(api)
```

The Go SDK in `.aspire/modules/` is generated by `aspire restore` from the
packages listed in `aspire.config.json`; don't edit it by hand.

## Prerequisites

- Aspire CLI 13.6.4 and the .NET 10 SDK
- Go 1.26+ (for both the AppHost and the API)
- Node.js 22.12+
- Docker (for PostgreSQL)

> **Windows:** Aspire 13.6's generated Go client can hang during named-pipe
> authentication ([microsoft/aspire#20056](https://github.com/microsoft/aspire/issues/20056)).
> Run this sample on Linux or macOS, or use the repository's
> [Linux validation runner](../../../docs/samples-and-development.md#linux-validation-for-windows-preview-hosts).

## Run

```bash
cd samples/preview/svelte-go-bookmarks
aspire run --apphost apphost.go
```

Open **frontend** from the dashboard, then:

- Add a bookmark with comma-separated tags, search by title/tag/URL, and delete it.
- Open **Traces**: each request shows the Go HTTP span with a child span per SQL query.
- Open **Structured logs**: `slog` records (`created bookmark id=…`) linked to their traces.

## How it is wired

- `WithReference(db)` injects `BOOKMARKSDB_URI`; the API opens it with the `pgx`
  driver wrapped by `otelsql`. No DSN building, no hard-coded credentials.
- `WaitFor(db)` holds the API until PostgreSQL and the database are healthy.
- `WithReference(api)` gives Vite `API_HTTP`, which `vite.config.js` uses to proxy `/api`.
- [`telemetry.go`](go-api/telemetry.go) uses `autoexport` to read Aspire's `OTEL_*`
  settings; logs go to stdout and the dashboard.

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/bookmarks` | List bookmarks |
| GET | `/api/bookmarks/search?q=go` | Search titles, tags, and URLs |
| POST | `/api/bookmarks` | Create a bookmark |
| DELETE | `/api/bookmarks/{id}` | Delete a bookmark |
| GET | `/health` | Health, including a database ping |
